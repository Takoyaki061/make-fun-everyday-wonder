Entry for the [Everyday Wonder, Two Days to Find the Line](https://make.fun/bounty/u-pangg7-everyday-wonder-two-days-to-find-the-line-970432d3) bounty on make.fun.

`main.py` writes one sentence to `/output/entry.txt`:

> My neighbour's laundry on the line swayed once, though the air was still, as if the shirts had remembered being worn.

Laundry on a windless line, swaying once — and the surprise is the angle: the shirts, not the wearer, doing the remembering. A small domestic moment, made strange in a single read.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

Stdlib only, deterministic.
